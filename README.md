## 🗺️ Roadmap

- [roadmap.sh — PostgreSQL DBA Roadmap](https://roadmap.sh/postgresql-dba) — Trilha visual e interativa para virar administrador(a) de banco de dados usando PostgreSQL como referência.
- [roadmap.sh — SQL Roadmap](https://roadmap.sh/sql) — Roadmap da linguagem SQL: do SELECT básico a janelas, índices e transações — base para qualquer trilha de PostgreSQL.
- [PostgreSQL — Roadmap oficial](https://www.postgresql.org/developer/roadmap/) — Página oficial do projeto sobre como as versões são planejadas e desenvolvidas.
- [PostgreSQL — Política de versionamento](https://www.postgresql.org/support/versioning/) — Como funcionam as versões maiores/menores e por quanto tempo cada uma recebe suporte.
- [PostgreSQL — Sobre o projeto](https://www.postgresql.org/about/) — Visão geral do projeto, história e por que o PostgreSQL é considerado o banco open source mais avançado do mundo.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Fundamentos** — o que é um SGBD relacional, tabelas, linhas, colunas, chaves primária e estrangeira.
2. **SQL básico** — `SELECT`, `WHERE`, `ORDER BY`, `INSERT`, `UPDATE`, `DELETE`, `CREATE TABLE`, tipos de dados nativos do PostgreSQL (incluindo `JSONB` e arrays).
3. **SQL intermediário** — `JOIN`, `GROUP BY`, subconsultas, CTEs (`WITH`), views, funções de janela.
4. **PL/pgSQL** — funções, triggers e procedures escritas na linguagem procedural do próprio banco.
5. **Performance** — índices (B-tree, GIN, GiST, BRIN), `EXPLAIN`/`EXPLAIN ANALYZE`, particionamento de tabelas.
6. **Administração** — instalação, usuários e permissões (roles), backup e restore, `VACUUM`, monitoramento.
7. **Alta disponibilidade e escala** — replicação, failover com Patroni/repmgr, pooling de conexões com PgBouncer.
8. **Extensões e IA** — PostGIS (geoespacial), pgvector (busca vetorial), TimescaleDB (séries temporais) e uso de IA para escrever e revisar SQL.

## 🛠️ Ferramentas

> Clientes e administração

- [pgAdmin](https://www.pgadmin.org/) — A ferramenta gráfica oficial de administração do PostgreSQL.
- [DBeaver Community](https://dbeaver.io/) — Cliente universal gratuito e open source, com suporte completo a PostgreSQL.
- [pgcli](https://www.pgcli.com/) — Cliente de terminal para PostgreSQL com autocompletar, realce de sintaxe e histórico inteligente.
- [TablePlus](https://tableplus.com/) — Cliente nativo, rápido e bonito, com versão gratuita limitada.
- [DataGrip](https://www.jetbrains.com/datagrip/) — IDE profissional da JetBrains para PostgreSQL e outros bancos; gratuita para estudantes. Pago para uso comercial.
- [Beekeeper Studio](https://www.beekeeperstudio.io/) — Editor SQL moderno e open source, multiplataforma.
- [DbGate](https://www.dbgate.io/) — Cliente open source para bancos SQL e NoSQL, desktop ou web.
- [Postgres.app](https://postgresapp.com/) — A forma mais simples de instalar e rodar o PostgreSQL no macOS.

> Análise de planos e monitoramento

- [pgModeler](https://pgmodeler.io/) — Modelador open source específico para PostgreSQL, com geração automática de SQL.
- [explain.dalibo.com (pev2)](https://explain.dalibo.com/) — Cole a saída do EXPLAIN e veja o plano de execução da consulta de forma visual.
- [pgMustard](https://www.pgmustard.com/) — Analisa o EXPLAIN ANALYZE e aponta em texto simples o que está deixando a consulta lenta. Ferramenta paga com teste gratuito.
- [pgBadger](https://pgbadger.darold.net/) — Analisador de logs do PostgreSQL com relatórios detalhados de consultas lentas.
- [pganalyze](https://pganalyze.com/) — Monitoramento e ajuste de performance para PostgreSQL em produção. Ferramenta paga com teste gratuito.
- [PGTune](https://pgtune.leopard.in.ua/) — Calculadora online que sugere valores de configuração do postgresql.conf a partir do hardware disponível.

> Alta disponibilidade, backup e escala

- [pgBackRest](https://pgbackrest.org/) — Ferramenta open source de backup e restore confiável, usada em produção por grandes empresas.
- [Patroni](https://patroni.readthedocs.io/) — Template para alta disponibilidade de PostgreSQL com failover automático via etcd, ZooKeeper ou Consul.
- [repmgr](https://www.repmgr.org/) — Ferramenta open source para gerenciar replicação e failover em clusters PostgreSQL.
- [PgBouncer](https://www.pgbouncer.org/) — Pooler de conexões leve, essencial para aplicações com muitas conexões simultâneas.
- [CloudNativePG](https://cloudnative-pg.io/) — Operador Kubernetes para rodar clusters PostgreSQL nativamente na nuvem, mantido pela EDB.
- [Zalando Postgres Operator](https://github.com/zalando/postgres-operator) — Outro operador Kubernetes popular para criar e gerenciar clusters PostgreSQL.

> Extensões

- [pgvector](https://github.com/pgvector/pgvector) — Extensão oficial que adiciona busca por similaridade vetorial ao PostgreSQL — a base do PostgreSQL para IA.
- [PostGIS](https://postgis.net/) — A extensão geoespacial mais usada do mundo, transforma o PostgreSQL em um banco de dados geográfico completo.
- [Citus](https://www.citusdata.com/) — Extensão que transforma o PostgreSQL em um banco distribuído horizontalmente, mantida pela Microsoft.
- [Tiger Data (ex-TimescaleDB)](https://www.timescale.com/) — Extensão especializada em séries temporais em escala de petabytes sobre PostgreSQL.
- [pg_cron](https://github.com/citusdata/pg_cron) — Extensão para agendar tarefas SQL periódicas direto dentro do banco, com sintaxe de cron.

> Nuvem e serviços gerenciados

- [Supabase](https://supabase.com/) — PostgreSQL gerenciado com API, autenticação, storage e vetores; alternativa open source ao Firebase.
- [Neon](https://neon.com/) — PostgreSQL serverless com branching de banco de dados como se fosse Git.
- [Crunchy Bridge](https://www.crunchydata.com/products/crunchy-bridge) — PostgreSQL gerenciado com foco em segurança e extensões avançadas (PostGIS, pgvector).
- [Amazon RDS para PostgreSQL](https://aws.amazon.com/pt/rds/postgresql/) — Serviço gerenciado de PostgreSQL da AWS, com backups e replicação automatizados.
- [Cloud SQL para PostgreSQL — Google Cloud](https://cloud.google.com/sql/docs/postgres?hl=pt-br) — Documentação em português do serviço gerenciado de PostgreSQL do Google Cloud.
- [Banco de Dados do Azure para PostgreSQL — Microsoft Learn](https://learn.microsoft.com/pt-br/azure/postgresql/) — Documentação em português do PostgreSQL gerenciado da Microsoft Azure.
- [Docker Hub — imagem oficial do PostgreSQL](https://hub.docker.com/_/postgres) — A imagem oficial para rodar PostgreSQL em containers em segundos.

## 🤖 IA na prática

PostgreSQL é, hoje, um dos bancos de dados mais usados como infraestrutura de IA — não só um lugar onde a IA ajuda a escrever consultas, mas onde ela armazena e busca conhecimento. A regra de ouro continua a mesma: a IA propõe, o `EXPLAIN` e um ambiente de teste decidem.

**Para aprender**
- Cole uma consulta que você não entende e peça para a IA explicar cláusula por cláusula e reescrever com CTEs para ficar mais legível.
- Cole um erro (ex.: `ERROR: column "x" does not exist` ou `ERROR: syntax error at or near`) junto com a consulta e peça a causa e duas formas de corrigir.
- Descreva um sistema (ex.: "um blog com posts, autores e comentários") e peça o modelo lógico e o `CREATE TABLE` em PostgreSQL — depois critique: faltou índice? o tipo de coluna está certo? deveria usar `JSONB` em algum campo?
- Peça exercícios com gabarito sobre o tópico que está estudando (window functions, CTEs recursivas, particionamento) usando um banco de exemplo como o Pagila.
- Peça para explicar, linha a linha, a saída de um `EXPLAIN ANALYZE` real.

**Para trabalhar**
- **Text-to-SQL** já é produto: [Vanna](https://vanna.ai/) e [WrenAI](https://github.com/Canner/WrenAI) transformam perguntas em consultas PostgreSQL. Funciona bem para explorar dados; para relatórios oficiais, revise sempre.
- **Servidores MCP** conectam Cursor, Claude Code ou Copilot direto ao seu PostgreSQL: o assistente lê o esquema, executa consultas, analisa índices e explica planos. Use com um usuário **somente leitura** e nunca em produção sem revisão — o [Postgres MCP Pro](https://github.com/crystaldba/postgres-mcp) já nasceu com esse controle de permissões em mente.
- Use assistentes de IA para: escrever migrações, gerar dados de teste, criar índices a partir de um `EXPLAIN ANALYZE`, documentar tabelas e escrever testes de consultas.
- **pgvector** transformou o PostgreSQL em banco vetorial: embeddings, busca por similaridade e RAG rodam direto no banco que você já conhece, sem precisar de um banco vetorial dedicado — é a extensão por trás de produtos como Supabase e Neon.

**Limites e boas práticas**
- LLMs **inventam colunas, tabelas e funções** que não existem. Sempre forneça o esquema (`\d nome_da_tabela`) no prompt.
- Uma consulta "correta" pode ser **lenta ou perigosa** (full scan, `DELETE` sem `WHERE`, `UPDATE` em milhões de linhas). Rode em ambiente de teste, dentro de `BEGIN`/`ROLLBACK`, e leia o plano antes de aplicar em produção.
- Text-to-SQL erra mais em bancos reais do que em benchmarks — ambiguidade de negócio ("usuários ativos" significa o quê?) é a principal causa de erro.
- **Nunca cole dados pessoais ou segredos** (senhas, strings de conexão, dados de clientes) em ferramentas de IA sem a política de segurança da sua empresa. Lembre-se da LGPD.
- Entenda o que você executa: em produção e em entrevista técnica, a consulta é sua.

> Bancos vetoriais e busca semântica

- [pgvector](https://github.com/pgvector/pgvector) — A extensão que torna o PostgreSQL um banco vetorial de verdade: embeddings, busca por similaridade e índices HNSW/IVFFlat.
- [Supabase — AI & Vectors](https://supabase.com/docs/guides/ai) — Guia oficial de como usar pgvector no Supabase para embeddings e RAG.
- [Neon — AI Starter Kit](https://neon.com/docs/ai/ai-intro) — Como usar PostgreSQL serverless (Neon) como banco vetorial para aplicações de IA.
- [pgai — Timescale](https://github.com/timescale/pgai) — Ferramentas para construir RAG e busca semântica direto do PostgreSQL, chamando modelos de IA via SQL.

> Text-to-SQL e assistentes

- [Vanna](https://vanna.ai/) — Framework de text-to-SQL: treina um agente de IA no seu esquema PostgreSQL para responder perguntas em linguagem natural.
- [WrenAI](https://github.com/Canner/WrenAI) — Ferramenta open source de GenBI/text-to-SQL que conecta a bancos PostgreSQL e gera consultas a partir de perguntas.
- [EDB — Postgres AI](https://www.enterprisedb.com/) — Iniciativa da EDB para unir PostgreSQL e IA, com ferramentas e treinamentos gratuitos.

> MCP e assistentes de código

- [Postgres MCP Pro](https://github.com/crystaldba/postgres-mcp) — Servidor MCP que dá a assistentes como Claude Code ou Cursor acesso configurável de leitura/escrita e análise de performance ao seu PostgreSQL.
- [MCP Servers — Postgres (arquivo de referência)](https://github.com/modelcontextprotocol/servers-archived/tree/main/src/postgres) — Implementação de referência do protocolo MCP para PostgreSQL, mantida pela comunidade do Model Context Protocol.

## 🎓 Certificações

O PostgreSQL não tem um exame "oficial" único como Oracle ou Microsoft, mas a **EDB** — empresa que mais contribui com o desenvolvimento do banco — oferece trilhas de treinamento com certificados de conclusão reconhecidos pelo mercado. Muitas vagas de DBA PostgreSQL também aceitam certificações mais amplas de nuvem (AWS, Google Cloud, Azure) como diferencial, já que o PostgreSQL é a opção padrão de banco relacional nos três provedores.

- [EDB Postgres AI Training — trilhas com certificado](https://www.enterprisedb.com/training) — Cursos sob demanda da EDB, empresa que mais contribui com o PostgreSQL, com certificados de conclusão.

## 💼 Carreira e vagas

Quem domina PostgreSQL trabalha como **DBA** (administra, protege e otimiza o banco), **desenvolvedor(a) back-end** (modela e consulta no dia a dia), **engenheiro(a) de dados** (pipelines e integrações) ou **engenheiro(a) de banco de dados** (internals, alta disponibilidade, escala). É, de longe, o banco relacional mais pedido em vagas de back-end e dados no Brasil — pesquise por "PostgreSQL", "Postgres", "SQL" e "DBA" nos agregadores abaixo.

- [ProgramaThor](https://www.programathor.com.br/) — Vagas de tecnologia no Brasil, incluindo posições de DBA e back-end com PostgreSQL.

- [Coodesh](https://coodesh.com/) — Vagas remotas de tecnologia com processos seletivos técnicos, incluindo SQL e bancos de dados.

- [We Work Remotely — vagas de programação](https://weworkremotely.com/categories/remote-programming-jobs) — Um dos maiores agregadores internacionais de vagas remotas de programação, incluindo DBA e back-end.
